(WebP is universally supported and encodes reliably; AVIF was dropped because a bad/partial AVIF decode has no fallback.) Params (dict): src path under assets/ (e.g. "images/events/5/group-pic.jpeg") [required] page optional Page — resolves page-bundle resources first alt alt text (default "") class class on the sizes sizes attr (default "100vw") loading "lazy" (default) or "eager" fetchpriority optional ("high" for LCP image) widths resize widths (default 400 800 1200); capped to source width fill "WxH" to crop to a fixed ratio at 1x/2x instead of resizing quality JPEG/WebP quality (default 78) Falls back to a plain when src isn't a processable Hugo resource (e.g. an image still living under static/). */ -}} := int (index $d 0) }}{{ $bh := int (index $d 1) -}} {{- range $s := (slice 1 2) -}} {{- $w := mul $bw $s }}{{ $h := mul $bh $s -}} {{- if le $w $ow -}} {{- $spec := printf "%dx%d" $w $h -}} {{- $webp
