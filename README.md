# PGPune

Website for **[Postgres Pune](https://pgpune.in)**, built with [Hugo](https://gohugo.io/).
It's data-driven — most updates are edits to YAML files in `data/`.

## Local dev

```sh
brew install hugo
git clone https://github.com/pgdaypune/pgdaypune.github.io.git
cd pgdaypune.github.io
hugo server                # http://localhost:1313/
```

## Updating content

Each `data/*.yaml` file has a comment block explaining its fields.

| Change | File |
| --- | --- |
| Current edition (dates, venue, countdown, CFP/registration status, stats) | `data/event.yaml` |
| Schedule / agenda | `data/schedule.yaml` |
| Speakers | `data/speakers.yaml` |
| Sponsors | `data/sponsors.yaml` |
| Organizers & community blurb | `data/about.yaml` |
| Site title, base URL, analytics, search | `hugo.yaml` |

- **Speakers** are data-driven — add an entry to `data/speakers.yaml`, pages are generated by `content/speakers/_content.gotmpl`.
- **Past events** — add a markdown file in `content/events/` (e.g. `7.md`).
- **Page copy** (about, CFP, register, code of conduct) lives in `content/*.md`.

## Deploy

Push to `main` — the [GitHub Actions workflow](/.github/workflows/hugo.yml) builds and deploys to GitHub Pages automatically.
